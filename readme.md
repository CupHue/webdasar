# Personal Portfolio Website

Website portofolio pribadi sederhana yang dibuat sebagai penugasan web dasar.

## Tech

- **HTML5**
- **BUN**
- **Tailwind CSS v4**
- **JavaScript (ES Modules)**
- **GSAP** — Animasi SVG & gambar

## Struktur Proyek

```
webdasar/
├── assets/
│   ├── education/       # Foto institusi pendidikan
│   ├── experience/      # Foto pengalaman
│   └── me/              # Foto profil
├── node_modules         # Modul - modul framework 
├── script/
│   └── main.js          # Logic JS & animasi GSAP
├── style/
│   ├── input.css        # Source Tailwind CSS
│   └── output.css       # Compiled CSS
├── index.html           # Halaman utama
└── readme.md
```

## Run Proyek

1. **Extract** zip ini
2. Install dependencies, untuk mencegah kehilangan dependency:
   ```bash
   bun install
   ```
3. Build Tailwind CSS:
   ```bash
   bun run dev
   ```
4. Buka `index.html` di browser (gunakan Live Server)
